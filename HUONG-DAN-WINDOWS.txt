tetoMIDI player - HUONG DAN CHAY TREN WINDOWS
================================================

CACH CHANH (de nhat)
  1. Giai nen file zip (chuot phai > Extract All).
  2. Mo thu muc njsjs-main, nhan dup vao:  START-tetoMIDI-WINDOWS.bat
  3. Lan dau chay: file nay tu tu cai PySide6 + cac thu vien can (can internet).
  4. Lan sau chi can nhan dup vao file .bat la choi ngay.

NEU CHUA CO PYTHON
  1. Tai Python 3.10 tro len:  https://www.python.org/downloads/
  2. Khi cai, NHO tick  "Add python.exe to PATH"
  3. Chay lai START-tetoMIDI-WINDOWS.bat

SUA LOI "no Qt platform plugin could be initialized"
  Loi nay la do thu vien PySide6 bi hong hoac may thieu VC++ runtime.
  Cach 1 (nhanh nhat): chay lai START-tetoMIDI-WINDOWS.bat - no tu phat hien
     va tu cai lai PySide6 ho mik.
  Cach 2 (thu cong): mo CMD roi chay 2 lenh:
       python -m pip uninstall -y PySide6
       python -m pip install --force-reinstall PySide6
  Cach 3: cai Microsoft Visual C++ Redistributable 2015-2022 (x64):
       https://aka.ms/vs/17/release/vc_redist.x64.exe
  Sau do chay lai app.

CHAY BANG LENH (neu thich)
  cd duong-dan-toi-njsjs-main
  python main.py

LOI KHAC
  - Xem log chi tiet:  python main.py --debug
  - File log nam o:  %APPDATA%\tetoMIDI\logs\tetomidi.log
